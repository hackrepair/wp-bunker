# Bunker 1.2.11

A tidy-up release. Nothing changes in how Bunker behaves.

## Changes

- Removed an unused debugging method, an unused loop variable and three redundant type casts.
- Removed the leftover handling of HTTPS settings from an unreleased 1.2.2 build. Bunker has not managed HTTPS since 1.2.3.

## Checked

All 20 standalone test suites pass on PHP 7.4 and 8.4, PHPCS is clean, and static analysis (Psalm taint, PHPStan, Semgrep) and a secret scan report nothing new. A WordPress security-audit code scan found no real issues. The release was installed on a WordPress 7.1 test site with the alert settings intact.

## Install

Download `thrg-bunker.1.2.11.zip`, upload it under **Plugins → Add New → Upload Plugin**, activate it and open **Settings → Bunker**. Installed copies update from the Plugins screen. Requires WordPress 6.9.4 or newer and PHP 7.4 or newer.
