# Bunker 1.2.13

A small update to the plugin details window. Nothing changes in how Bunker behaves.

## Changes

- The **Other THRG Plugins** tab in View details now also lists Stickies.

## Install

Download `thrg-bunker.1.2.13.zip`, upload it under **Plugins → Add New → Upload Plugin**, activate it and open **Settings → Bunker**. Installed copies update from the Plugins screen. Requires WordPress 6.9.4 or newer and PHP 7.4 or newer.
