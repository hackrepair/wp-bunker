# Bunker 1.2.14

Hardening for uploads protection and the hatch approval flow.

- Deny uppercase and double-extension PHP filenames in uploads, including equivalent Nginx guidance.
- Replace the predictable shared-temp hatch lock with a salt-derived database advisory lock. Contention or unsupported locks refuse new requests safely.
- Use Secure cookies and HTTPS hatch links when WordPress has HTTPS configured or detected, including proxy configurations.
- Simplify the introductory heading as requested, preserving the confirmation step.
- Show a nonblocking HTTP advisory. Hosting owners still manage HTTPS; Bunker does not rewrite site URLs or hosting redirects.

The hatch still requires email approval and normal WordPress authentication. These changes do not establish that any site was compromised. Database proxies/clusters must retain one server/session for advisory locking. Nginx rules remain a hosting configuration task.

Download `thrg-bunker.1.2.14.zip` or update from the WordPress Plugins screen. Requires WordPress 6.9.4+ and PHP 7.4+.
