# Bunker 1.2.12

A friendlier introduction. Nothing changes in how Bunker behaves.

## Changes

- The plugin description under **View details** now starts from the situation Bunker is built for: a static website at the front, with WordPress quietly behind it for the forms, and bots knocking on the WordPress parts nobody else visits.
- The security alerts are explained in a few short sentences instead of one long paragraph.
- The GitHub README and project description were rewritten in the same plainer voice.

## Install

Download `thrg-bunker.1.2.12.zip`, upload it under **Plugins → Add New → Upload Plugin**, activate it and open **Settings → Bunker**. Installed copies update from the Plugins screen. Requires WordPress 6.9.4 or newer and PHP 7.4 or newer.
